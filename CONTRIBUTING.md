# Contributing

Corrections, technical error reports and suggestions that make these resources clearer for Product Managers are welcome.

## Report a problem or suggest a clarification

[Open an issue](https://github.com/The-Product-Shelf/technical-product-manager-resources/issues) with the resource name, the relevant passage and what needs attention. Include an authoritative reference when reporting a technical error, and describe any context that changes the answer.

## Propose a correction

You can also open a pull request with a focused change. Explain the problem and how your edit improves accuracy or clarity. Keep the existing plain-English, Product Manager perspective and preserve qualifications, examples and links that remain useful. Check relative links and Markdown formatting before submitting.

This library currently covers 14 resources in seven topics. Please discuss larger changes in an issue first; keep corrections separate from proposals to expand the library.

## Keep examples safe to share

Do not include confidential data, customer information, credentials, API keys or sensitive internal examples in issues, pull requests, screenshots or sample data. Use fictional or synthetic examples that demonstrate the problem without exposing private information.

## Licensing

Contributions are reviewed for inclusion under the repository's existing [CC BY-NC 4.0 license](LICENSE.md). Submit only material you have the right to contribute, and identify any third-party material and its terms.
